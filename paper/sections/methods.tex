\section{Methods}\label{sec:methods}

Let $Y$ denote the response, let $X \in \mathbb{R}^p$ denote the predictors, and let $g \in \{1,\dots,G\}$ index observed subgroups. The subgroup sample size is $n_g$, the subgroup coefficient for predictor $j$ is $\hat{\beta}_{j,g}$, and the pooled coefficient is $\hat{\beta}_{j,\mathrm{pool}}$. We treat the pooled regression as the estimand to be assessed, not as a benchmark assumed to be correct. The analysis records five complementary diagnostics of subgroup disagreement.

For $\mathrm{SSR}_j$, the pairs $(a_m,b_m)$ are all pairwise comparisons of subgroup-specific coefficient signs. The prediction gap is evaluated within each target group and then averaged across groups; it is not a pairwise source-to-target prediction experiment.

Higher values of $D_j^{\star}$, $\widetilde{D}_j$, $\mathrm{TPG}_{a \to b}$, and $\mathrm{CSS}_{a,b}$ indicate greater instability or mismatch, while higher $\mathrm{SSR}_j$ indicates greater directional stability.

\subsection{Regression Models Compared}

For each dataset or simulated replicate, we fit four linear regression specifications. The pooled model is
\[
Y = \beta_0 + X^\top \beta + \varepsilon,
\]
which imposes a single coefficient vector across all subgroups. The second adds a group indicator,
\[
Y = \beta_0 + X^\top \beta + \gamma G + \varepsilon,
\]
which allows subgroup-specific intercept shifts but keeps slopes common. The third adds interactions,
\[
Y = \beta_0 + X^\top \beta + \gamma G + X^\top \delta G + \varepsilon,
\]
which allows the slope coefficients to vary by subgroup. The fourth fits separate subgroup-specific OLS models, so that each group has its own intercept and slope vector.

The pooled and separate models provide the quantities used in the diagnostics. The group-indicator and interaction models provide conventional reference specifications for intercept and slope differences. The comparison is descriptive; no single model is treated as the universally correct alternative.

\subsection{Simulation Design}

The simulation starts with a common-slope baseline and then varies the source of subgroup disagreement. It changes total sample size, the number of groups, group-size imbalance, and whether predictor means or regression coefficients differ across groups. The predictor correlation is fixed at $\rho=0.2$, the outcome noise standard deviation is one, and there are two predictors. The four scenarios are: common predictor distributions and slopes; shifted predictor means with common slopes; common predictor distributions with shifted slopes; and simultaneous shifts in means and slopes.

For every replicate, we generate data, fit the four regressions, and retain the pooled and subgroup-specific coefficients and prediction errors. Each reported setting-level result is the average of replicate-level diagnostics. The simulation is designed to characterize finite-sample behavior under these specified mechanisms, not to estimate a universal threshold for deciding whether a pooled model should be used.

\subsection{Interaction-Test Benchmark}

We compare the diagnostic framework with the conventional test for slope interactions. The benchmark compares the group-intercept model to the model with group-specific slopes using the nested-model F-test at level $\alpha=0.05$. It is run on a reduced grid with $G \in \{3,15,40\}$, $n \in \{300,3000,30000\}$, and balanced or random group-size allocation. The four data-generating scenarios are retained, and each scenario-setting cell is replicated 200 times. The benchmark reports the proportion of replicates rejecting common slopes. It is intended as a reference comparison rather than a replacement for the descriptive diagnostics, which quantify coefficient movement, covariate separation, and pooled-versus-subgroup prediction loss.

\subsection{Real-Data Workflow}

The empirical analysis uses the same workflow. After defining the response, predictors, and subgroup variable, we fit the pooled, group-indicator, interaction, and separate subgroup regressions. We then compare coefficient diagnostics and the pooled-versus-subgroup prediction gap within each group.

To assess predictive performance beyond the estimation sample, we also use repeated stratified cross-validation. Within each repetition, observations are assigned to folds separately within each subgroup. A pooled model is fitted on the combined training observations, while a separate model is fitted for each subgroup using its training observations. Both models are evaluated on the held-out observations from that subgroup. The reported RMSE difference is $\mathrm{RMSE}_{\mathrm{pooled}} - \mathrm{RMSE}_{\mathrm{group}}$, so positive values favor the group-specific model. The empirical analysis remains illustrative. It does not identify causal effect modification or establish that the observed subgroup patterns generalize beyond the selected specification.

\subsection{How the Metrics Are Used}

Sign stability asks whether coefficient directions agree. Standardized drift measures the largest subgroup departure from the pooled coefficient on a common scale. Context-normalized drift places that departure in relation to observed subgroup mean separation. The prediction gap measures the within-group cost of using the pooled model rather than the group-specific model. Covariate shift summarizes differences in predictor means. These quantities should be read jointly. None is a formal test of a common slope, and none on its own identifies the source of subgroup disagreement.
